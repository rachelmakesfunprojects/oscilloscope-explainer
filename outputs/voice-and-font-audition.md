# Voice and handwritten font audition

The new audition was generated in ElevenLabs with **Christopher — Gentle and Trustworthy**, a British voice, using **Eleven Multilingual v2** at a **1.08 speed setting**. It uses the same 124-word sample as the earlier Ryan recording. The export runs **45.37 seconds**, versus **60.84 seconds** previously, so this is a noticeably brisker interpretation. The speed setting is relative to Christopher’s own default delivery, not the previous voice.

[Play or download the ElevenLabs audition](narration-sample-elevenlabs-christopher.mp3)

ElevenLabs worked through the account already signed in in Safari after the in-app browser sign-in failed. This does not install an API connector. The MP3 was decoded and checked for duration and non-silent audio.

## Font recommendation

My recommendation is **Caveat for the title and subtitle**, with **Patrick Hand for detailed labels**. The full frame retains the original B wording and whiteboard palette, with the additional technical labels.

[Six font comparison](handwritten-font-options.png) · [Recommended pairing in the full frame](font-recommended-pairing.png)

The six options are Caveat, Patrick Hand, Kalam, Handlee, Architects Daughter, and Indie Flower. The samples use actual font files without chalk texture. No final font selection has been applied to the storyboard.

See [font sources, designers, licences and individual previews](font-options.md). Original code draws the diagrams.
